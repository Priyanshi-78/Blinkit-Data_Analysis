# Blinkit Sales Analysis | Data Analytics Project

## Project Overview
An exploratory data analysis (EDA) project focused on examining Blinkit's grocery sales data to understand sales performance, product trends, and outlet characteristics.

The project aims to transform raw data into meaningful insights that support data-driven business decision-making.

## Objectives
- Examine overall sales performance and trends.
- Analyze product-wise sales distribution.
- Evaluate outlet performance across different categories.
- Identify patterns and trends within the dataset.
- Generate meaningful business insights through data analysis.

## Tech Stack
- **Python** – Programming and Analysis
- **Pandas** – Data Manipulation
- **NumPy** – Numerical Computing
- **Matplotlib** – Data Visualization
- **Seaborn** – Statistical Visualization
- **Jupyter Notebook** – Development Environment

## Project Workflow
1. Data Exploration
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Insights & Interpretation
